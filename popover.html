Popover API Demo

The Popover API provides developers with a standard, consistent, flexible mechanism for displaying popover content on top of other page content. Unlike a <dialog> — which is suited for formal interactions that may require user input, trap focus, or block the page — a popover is lightweight and non-blocking. It supports light dismiss (clicking outside closes it automatically) and leaves the rest of the page fully interactive.

For more information visit the Popover API page on MDN
