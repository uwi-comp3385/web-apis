Dialog Demo

The <dialog> HTML element represents a modal or non-modal dialog box or other interactive component, such as a dismissible alert, inspector, or subwindow. Unlike the popover attribute — which is lightweight, non-blocking, and intended for transient UI like tooltips or menus — a dialog is a formal interaction point that can trap focus, return a value, and optionally block the rest of the page via a backdrop.

For more information visit the Dialog Element page on MDN.

1. Invoker Commands API New

The Invoker Commands API lets you open and close a dialog entirely in HTML — no JavaScript required — using the command and commandfor attributes.

Browser support: The Invoker Commands API is very new. Check caniuse.com before using in production.

2. JavaScript API — showModal()

dialog.showModal() opens the dialog as a modal: it receives focus, traps keyboard navigation inside it, renders a ::backdrop, and can be dismissed with Escape.

JavaScript Modal Dialog

Opened with dialog.showModal(). Notice the blurred backdrop behind it.

Focus is trapped inside this dialog — try pressing Tab.

3. Return Values with <form method="dialog">

A <form> inside a dialog with method="dialog" will close the dialog when submitted. The submit button's value is captured as dialog.returnValue, making it easy to know which action the user chose.

4. Non-modal Dialog — show()

dialog.show() opens the dialog as non-modal: there is no backdrop, focus is not trapped, and the rest of the page remains fully interactive. It behaves more like a floating panel or toast.
